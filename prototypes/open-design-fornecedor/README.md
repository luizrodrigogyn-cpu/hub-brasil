# Protótipo isolado — fornecedor

Preview de design para aprovação. Não importa módulos do app, não chama APIs, não acessa autenticação e não grava dados.

Abra `index.html` em um servidor estático. Use os botões “Cockpit”, “Cadastro” e “Perfil público” para navegar pelos três estados. No cadastro, “Continuar” e “Voltar” demonstram progressive profiling sem enviar o formulário.

## Origem e licenças

Não há componentes externos. HTML, CSS, JavaScript e SVGs foram criados para esta proposta. OpenDesign orienta apenas o fluxo de trabalho e não está embutido no produto.
